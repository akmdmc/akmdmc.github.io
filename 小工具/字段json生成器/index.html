字段json生成器

      格式：  
  "title": {
    "title": "Title",
    "type": "string",
    "widget": "input"
  }
  注：索引的首字母小写且去除空格
      
            格式：{"title":"Title","dataIndex":"title"}
        注：dataIndex首字母小写且去除空格

    使用说明

    1. 输入字段名，按回车键添加字段

    2. 点击字段后的删除按钮可以删除字段

    3. 生成后，copyBoard的内容会自动复制到剪贴板
